One number I calculated by hand in Flex 3 was the profit margin percentage, which I calculated by dividing profit by total sales in my profitability analysis. In Power BI, I would build this as a measure because the margin needs to recalculate when the report is filtered by product, region, or time period. Having the calculation in the data model means Anita or Marcus could explore the margin themselves instead of asking me to recalculate it for every view. It would also keep the number consistent and updated whenever the underlying data changes.
